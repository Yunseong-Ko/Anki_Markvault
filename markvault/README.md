# MarkVault

Anki 에서 플래그·Mark 를 단 카드를 Markdown 폴더로 자동으로 모아 주는 애드온. 어떤 덱·노트 유형이든 동작.

## 설치
Anki → 도구 → 추가 기능 → 파일에서 설치… → `markvault.ankiaddon` → Anki 재시작

## 사용
- 평소처럼 공부하며 빨간 플래그(Ctrl+1) 또는 Mark(Ctrl+K)
- **동기화 버튼을 누르면** 끝난 직후 `~/Documents/Anki 복습/복습 카드.md` 가 갱신된다 (Anki 를 열 때도 한 번)
- 도구 → MarkVault → 지금 내보내기 / 출력 폴더 열기 / PDF·docx 로 내보내기… / 설정…
- 카드 블록 아래에 `> [!note] 내 메모` 콜아웃을 적어 두면 다음 갱신에도 남는다
- 카드로 돌아가려면 Anki 브라우저 검색창에 메타 줄의 `cid:…` 를 붙여넣기

## 파일
- `복습 카드.md` 전체 (덱 경로별 소제목) · `_목차.md` 덱 → 카드 제목 · `_색인.md` 장수 · `_media/` 이미지
- 옵션: `_해제됨.md`(플래그 풀린 카드), `_주간/2026-W44.md`(그 주 새로 표시한 카드)
